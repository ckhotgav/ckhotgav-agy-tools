# 專案駕駛艙工作流程 — 收工

## 🔚 收工流程 (當說「收工」、「下班」、「結束」、「Shutdown」、「End」時載入)
請 AI 助理依序引導執行以下步驟：

1. **確認存檔**：確認所有編輯中的檔案已儲存。
2. **變更成果比對**：執行 `git status` / `git diff` 條列出今日新增或修改了哪些檔案。
3. **自動更新 PROJECT.md**：將今天完成的事項在 `PROJECT.md` 中標記為已完成，並新增未完任務。
4. **更新 Obsidian 每日工作日誌**：將今天完成的條列式摘要與明日待辦事項，寫入 Obsidian 筆記的 `每日筆記/<今日日期>.md` 中。
5. **互動式引導（詢問使用者，獲得同意才執行）**：
   * 📁 *「需要我幫您把今天的變更 Commit (提交) 嗎？（我已為您寫好 Commit 訊息：`feat: update...`）」*
   * ☁ *「需要幫您 Push 到 GitHub 嗎？」*
   * 🚀 *「需要幫您部署至雲端 (Netlify / Vercel) 嗎？」*
   * 🔄 *「需要將今日變更同步上傳到 NotebookLM 嗎？」*
6. **安全掃描**：自動掃描今日有修改的檔案，確認沒有將硬編碼的 API Key、密碼、Token 誤寫入並準備 Commit。
7. **溫馨回報**：確認全部就緒後，向使用者回報本日收工 checklist，並貼心地說一聲「辛苦了，明天見！👋」
