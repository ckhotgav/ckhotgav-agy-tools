# 技能 20：PHP + MySQL 資料庫連線實戰

串接你的第一支後端程式，製作一個會自動累計人數的「訪客計數器」。

## 步驟 1：讓 AI 撰寫 PHP 資料庫連線檔
將你在技能 19 中申請的 MySQL 資料庫資訊（主機、名稱、帳號、密碼）提供給 AI 助理。
AI 會為你產生：
* `db.php`：資料庫連線設定與連線錯誤處理。
* `index.php`：讀取資料庫、累加訪問次數並呈現在網頁上的主要程式碼。

## 步驟 2：上傳至 FTP
使用 FileZilla 將 `db.php` 與 `index.php` 上傳至 `public_html` 資料夾。

## 步驟 3：測試動態網站
打開瀏覽器輸入 `你的網址/index.php`。
確認畫面有顯示「資料庫連線成功」以及「你是第 XXX 位訪客！」。
若有錯誤，將錯誤訊息貼給 AI，AI 助理會自動幫你修正 PHP 連線語法。
