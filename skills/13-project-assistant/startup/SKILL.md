# 自動專案助理工作流程 — 開工

## 🔛 開工流程 (當說「開工」、「我來了」、「開始」、「Begin」、「Start」時載入)
請 AI 助理依序執行以下步驟：

1. **AI 工具設定檔安全備份**：依據不同的工具環境，自動尋找並備份專屬的設定檔（純保留作為安全備份）：
   - **OpenCode**：將 `%USERPROFILE%\.config\opencode\opencode.jsonc` 備份為 `.bak`。
   - **Antigravity**：備份對應的 Antigravity 設定檔（路徑待查明後補充）。
   - **Cloud Code**：備份對應的 Cloud Code 設定檔（路徑待查明後補充）。
   - **Codex**：備份對應的 Codex 設定檔（路徑待查明後補充）。
   *(AI 會自動判斷這些路徑是否存在，存在則執行備份。)*
2. **檢查 Git 倉庫**：確認工作目錄是否為一個有效的 git repository。
3. **目錄掃描**：確認當前目錄下的主要檔案結構。
4. **讀取專案進度檔**：**優先讀取並分析專案目錄下的 `PROJECT.md`**，了解前一次開發的里程碑與目前 TODO 事項。
5. **讀取 Obsidian 每日筆記**：讀取 Obsidian 庫中的 `每日筆記/<今日日期>.md`，掌握上次工作記錄與排程。
6. **檢查知識庫整理狀態**：讀取 Obsidian 庫中的 `_整理記錄.md`，比對 `last_organize` 日期。若超過 `interval_days` (預設 14 天) 未整理，需在最後的開工摘要中特別提醒。
7. **確認工作變更**：執行 `git status` 檢查是否有未 Commit 的檔案變更。
8. **環境健康確認**：報告專案目前的健康度。
9. **回報開工摘要**：回報一份精美的 Markdown 狀態報告，包含：
   * 「歡迎回來！目前專案狀態：...」
   * 若超過 14 天未整理筆記，加入提醒：「💡 溫馨提醒：您的知識庫已經超過 14 天未整理，請問今天要進行整理嗎？」
   * 「今日推薦下一步：...」
   * 詢問使用者：「我們今天準備從哪裡開始？」

> ⚠️ **安全原則：開工只讀不寫。**
