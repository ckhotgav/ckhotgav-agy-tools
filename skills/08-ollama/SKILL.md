# 技能 08：Ollama 本地 AI

在沒有網路、完全免費的情況下，在自己電腦上運行 AI 模型。

## 步驟 1：下載安裝 Ollama
* 前往 https://ollama.com/download 下載並雙擊安裝。

## 步驟 2：下載輕量化模型 (如 llama3.2)
* 終端機執行：`ollama pull llama3.2`

## 步驟 3：運行與對話測試
* 終端機執行：`ollama run llama3.2`
* 在終端機對話框輸入「你好」測試是否能回覆，輸入 `/bye` 即可退出。
