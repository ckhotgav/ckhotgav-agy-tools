# 專案駕駛艙工作流程 — 開工

## 🔛 開工流程 (當說「開工」、「我來了」、「開始」、「Begin」、「Start」時載入)
請 AI 助理依序執行以下步驟：

1. **檢查 Git 倉庫**：確認工作目錄是否為一個有效的 git repository。
2. **目錄掃描**：確認當前目錄下的主要檔案結構。
3. **讀取專案進度檔**：**優先讀取並分析專案目錄下的 `PROJECT.md`**，了解前一次開發的里程碑與目前 TODO 事項。
4. **讀取 Obsidian 每日筆記**：讀取 Obsidian 庫中的 `每日筆記/<今日日期>.md`，掌握上次工作記錄與排程。
5. **確認工作變更**：執行 `git status` 檢查是否有未 Commit 的檔案變更。
6. **環境健康確認**：報告專案目前的健康度。
7. **回報開工摘要**：回報一份精美的 Markdown 狀態報告，包含：
   * 「歡迎回來！目前專案狀態：...」
   * 「今日推薦下一步：...」
   * 詢問使用者：「我們今天準備從哪裡開始？」

> ⚠️ **安全原則：開工只讀不寫。**
