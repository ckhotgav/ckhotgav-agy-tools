# 技能 18：其他雲端部署平台

除了 Netlify 之外，你也可以探索其他的免費雲端託管平台。

## 1. Vercel
* **特色**：前端託管的神器，特別適合 Next.js / React 網頁。
* **安裝**：`npm install -g vercel` -> `vercel login` -> `vercel` 一鍵部署。

## 2. Cloudflare Pages
* **特色**：速度極快、提供免費的無限流量與防 DDoS 保護。
* **安裝**：可直接透過 GitHub 儲存庫進行連動部署，每次 git push 都會自動更新網頁。
